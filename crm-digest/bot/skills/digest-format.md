# Zoho CRM Digest format

Mirror the public CRM Digest archive
(https://www.zoho.com/crm/resources/digest.html) and recent SharedView issues.

## Shape

1. **Subject line** — month + benefit hook (e.g. `March Digest: AI upgrades, new features and more`).
2. **Preview / intro** — 2–4 sentences: welcome, month theme, what the reader gets.
3. **What's New pointer** — short line pointing readers to the What's New page for the full list.
4. **Feature spotlights** (usually 2–4) — each with:
   - Benefit-led headline (not the raw release-note title)
   - 1–3 short paragraphs of plain, sales-team-friendly copy
   - Clear CTA (`Try it now`, `Read more`) using the real What's New / help link
5. **Closing** — invite reply feedback; keep it short.

## Voice

- Confident, concrete, benefit-first.
- Second person (“your team”, “you can”).
- No hype stacks, no emoji clusters, no invented metrics.
- Preserve DC / edition limitations when the source notes them.
- Do not invent features, dates, or links.

## Not in scope for v1 draft

HTML email chrome, social icons, subscribe forms, and Campaigns template markup.
Deliver clean markdown a designer can drop into the Digest template.
