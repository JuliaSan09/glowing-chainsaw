# Rebuild the Zoho Show deck from scratch

The presentation is generated by **one Python script**. It reads the SOP screenshots, writes Show-safe JPEGs (including CRM capture frames), zips the image pack, and embeds the SOP images in a 22-slide PPTX.

```bash
cd docs/ekya-admissions/show
pip install -r requirements.txt
python3 build_presentation.py
```

That writes, next to the script:

| Output | What it is |
| --- | --- |
| `Ekya-CMR-Admissions-Demo.pptx` | 22-slide deck — import this into Zoho Show |
| `images/*.jpg` | SOP stills + CRM capture frames |
| `Ekya-CMR-Admissions-Screenshots.zip` | Same JPEGs, for dropping onto Zia placeholders |

**Do not paste `build_presentation.py` into Zia Generate.** Import the PPTX: Zoho Show → **Import** (or WorkDrive → Open with Zoho Show).

Source SOP PNGs must stay in `docs/ekya-admissions/process-flow/`. The builder converts them to RGB JPEGs (max 1400px, no alpha) so Show and GitHub preview do not choke.

There is no Show API on this evaluation org. Native format after import is `.zslides`.

## Import into Zoho Show

1. Open [show.zoho.com](https://show.zoho.com) or [show.zoho.in](https://show.zoho.in) with the same Zoho account you use for CRM.
2. Use **Import** (or **Open** → **Import file**). A blank presentation is not required.
3. Choose `Ekya-CMR-Admissions-Demo.pptx`.
4. Save the converted file as **Ekya CMR Admissions Demo**.
5. Turn on **Presenter view** so speaker notes stay on your screen. The customer sees the slide only.

From WorkDrive: upload the PPTX, then **Open with Zoho Show**. WorkDrive can also **Convert to Zoho format**.

Do not insert images from the GitHub file preview. Download the zip or use the JPEGs the script just wrote.

## How to present (Show + CRM)

Use two windows. Show is the cue. CRM is the proof.

| Window | Role |
| --- | --- |
| Zoho Show | Advance one slide, read the CRM cue in the footer, glance at notes |
| Zoho CRM | Search and open the record named on the slide |

Do not stay on a slide while they could be looking at the live lead. Advance Show, then switch.

## Optional: Zia Generate instead of PPTX import

If you would rather start from Zia than import the PPTX, paste [zia-generate-prompt.txt](zia-generate-prompt.txt) into **Describe your presentation idea** (2,446 / 2,500 characters).

| Setting | Use |
| --- | --- |
| Slide Limit | Largest option available (not Small — Small will collapse the order) |
| Content Tone | Professional |
| Visual Style | Content with Placeholders |
| Theme | Basic or Executive |

Then **Generate Presentation**. Zia cannot attach images. After it builds, download [Ekya-CMR-Admissions-Screenshots.zip](Ekya-CMR-Admissions-Screenshots.zip), unzip, and drop the **.jpg** files onto placeholders ([SCREENSHOTS.md](SCREENSHOTS.md)).
